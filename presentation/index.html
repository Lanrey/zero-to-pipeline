The success criteria

It means ✓

  • First sync in under 5 minutes
  • Sane defaults for 90% of APIs
  • Name + credential = running
  • Transparent permission model

  • ✗ Skip security review
  • ✗ Works for every edge case
  • ✗ Replaces data modelling
  • ✗ Magic that hides everything

Pattern 1: Retries + Backoff


from tenacity import retry, wait_exponential, stop_after_attempt

@retry(
    wait=wait_exponential(multiplier=1, max=60),  # 1s → 2s → 4s... → 60s
    stop=stop_after_attempt(3),
    retry=retry_if_exception_type((TransportError, RateLimitError)),
)
async def request(self, method, path, **kwargs):
    response = await self._client.request(method, path, **kwargs)

    if response.status_code == 429:  # Rate limited
        retry_after = float(response.headers.get("Retry-After", "60"))
        await asyncio.sleep(retry_after)
        raise RateLimitError(retry_after)   # → tenacity retries

    response.raise_for_status()
    return response
TIMING: 17:30 — Pattern 1: the transient failure problem. "Every API call in that 4.4-second pipeline was wrapped in this decorator. Three lines. Exponential backoff from 1s to 60s. Three attempts." Point at the 429 block: "Rate limited? The API tells us exactly how long. We sleep that duration — not a guess. W&B's cloud API does this. MLflow local doesn't. Same code handles both transparently." Quick — move to Pattern 2, which resolves the 17:00 crash directly.

AUTH_FORMATS = [ ("Bearer", "Authorization"), # Standard — MLflow managed, W&B cloud ("", "Authorization"), # MLflow self-hosted, some internal APIs ("token", "Authorization"), # Airflow, older REST APIs ("", "X-API-Key"), # Grafana, some observability APIs ("", "Api-Key"), # Prometheus pushgateway, others ] for prefix, header in AUTH_FORMATS: response = await try_auth(prefix, header) if response.ok: self._auth_prefix = prefix # Saved — no more 401s on this source self._auth_header = header return response # Log: healing_success event emitted
